# Homat Labs

Reproducible, data-driven analyses behind the articles on [homatai.com](https://homatai.com). Each folder holds the data (or how to get it), a notebook that runs top to bottom, the figures, and the article text. Every number in an article is checked against the notebook's `results.json`.

| Folder | Topic |
|---|---|
| [iranian-telecom-churn](iranian-telecom-churn/) | Which customers will leave? Churn prediction on a real Iranian telecom dataset |

Code: MIT. Datasets and fonts keep their own licenses, noted in each folder.
